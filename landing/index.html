A canvas for governed agent teamwork

From isolated prompts to a shared workflow.

A node is a task with a prompt, an executor and a project context. Connections carry summaries, results, commands and artifacts into the next task.

01 / ORGANIZE

Team boards, real projects

Navigate departments and teams. Bind a project graph to an existing Git workspace, branch and revision.

02 / CONNECT

Tasks that build on each other

Connect implementation, analysis and test tasks. Choose an executor and reuse node templates instead of copying entire conversations.

03 / REVIEW

Context that survives the handoff

Pause at human review gates, request rework, and send a result to another team's inbox with its source context.

Bring a small project. Start locally.

Requires Node.js 24+, npm and Git. These instructions use a pinned preview revision that includes the authenticated backend and API model connections.

1. Get the preview

git clone https://github.com/Anton15K/IBM_HACK.git
cd IBM_HACK
git checkout 66a89853325e10f7636160117856dba65646a4f0
npm ci

Use an existing, trusted Git project as your agent workspace. Replace the example path with the parent directory containing that project.

2. Start the backend — terminal 1

TEAMWEAVE_WORKSPACE_ROOTS=/absolute/path/to/projects npm run dev:server

3. Start the frontend — terminal 2

npm run dev

Open localhost:5173/IBM_HACK/, register an organization, and create a team and project.

Start with Mock for a simulated run. Real agent execution needs your own configured provider and available quota. API model support is implemented; a successful live API coding run is not claimed here. The local runner is intended for trusted projects, not untrusted code.
