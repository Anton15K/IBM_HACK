# IBM Bob development evidence

This report describes demonstrated Bob participation in TeamWeave. It is an evidence index, not a claim of exclusive Bob authorship or complete submission coverage.

## Implementation and verification

Bob contributed the canvas/executor prototype, backend and Git workspace foundations, API model integration, placement contracts, and interface changes. Both Bob Shell and native Bob IDE sessions were used. Some early Shell tasks were later opened in the IDE for authentic summary captures. Tasks that stopped at their limits may have been finished or corrected separately.

Later team-authored work, including member onboarding and the run monitor, is not attributed to Bob. A commit or merge executed by Bob does not establish who wrote its contents. The runtime supports optional Bob Shell and API executors; it does not require Bob for every run.

## Cost and provenance

- Each task ID identifies one session; continuation values are cumulative. Repeated screenshots of one task must not be added together.
- Displayed IDE costs are rounded. The Lambdaderta inventory preserves more precise read-only local task records separately. Neither is the current available balance.
- No team-wide spend is claimed until each account is reconciled; task evidence is not a Bobalytics percentage.
- Screenshots are real IDE views. Existing JPEG-to-PNG conversions and capture hashes are documented in the contributor manifest. These files contain no synthetic task summaries.
- Full conversation exports, local databases, credentials, and machine-private operational records are deliberately excluded from this public repository. They are not substitutes for the required task-summary screenshots.
