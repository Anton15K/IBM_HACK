## Bob evidence

Each participant should repeat this for all project-related tasks:

1. Open Bob IDE and select **Tasks**.
2. Select **All** workspaces if project work spans several checkouts.
3. Open the relevant task, then its header to show the task session consumption summary.
4. Capture the genuine summary with its task ID, workspace, and Bobcoins. Prefer PNG and a filename such as `teamweave_member_task01_description.png`.
5. Check for credentials, personal data, and unrelated content before publication. Do not fabricate or redraw the summary.
6. Add the PNG to `bob_sessions/`, link it in the contributor index, and reconcile it against the task inventory.

Bob Shell is explicitly permitted as an optional tool; the guide also requires Bob IDE use. A screenshot of an old Shell task opened in the IDE must not be described as proof that its original implementation used the IDE.

Raw chats, task databases, and JSON session exports are not requested by the cited upload instructions. Keep them private. Git notes, cost tables, and Bobalytics screenshots do not replace task-summary PNGs.
